# @foldstryx/tokens

Astryx-faithful design tokens for StyleX. Exposes `colorVars`, `typographyVars`,
and the other token variable groups as StyleX `defineVars` defaults, plus the
`index.stylex.ts` module used by `@foldstryx/styles`.

```ts
import { colorVars } from '@foldstryx/tokens'
```

See the [root README](../../README.md) for the layer map and packaging notes.
